# 🏍️ עין יהב אונליין

משחק רשת על מושב עין יהב שבערבה: רוכבים על אופנועים, מטיילים עם חברים, קוטפים פלפלים, בונים בתים וקונים מכולות עם כלי רכב.

## הפעלה

```bash
npm install
npm start
```

פותחים במחשב את `http://localhost:3000`.
החברים (מחוברים לאותו WiFi) סורקים את קוד ה-QR שמופיע במסך הכניסה או בכפתור **📱 הזמן**, ונכנסים מהטלפון.

## מה יש במשחק

- **המפה**: המושב עם הרחובות, הכיכר, המכולת, בית הספר, הבריכה, מגדל המים, חממות הפלפלים, מטע התמרים, הדיונות, מסלול מוטוקרוס, כביש 90 והרי אדום.
- **כלי רכב**: אופנועים, טרקטורונים, ג'יפ וטרקטור. אפשר לעלות גם כנוסע על רכב של חבר: באופנוע יש מקום לשניים, ובג'יפ לארבעה.
- **מטבעות** 🪙: מקבלים 5 על כל פלפל 🌶️ שקוטפים בחממות, ועוד 2 כל 10 שניות של משחק.
- **בניית בית** 🏠: עולה 50 מטבעות. לא בונים על כביש ולא צמוד לבניין אחר. במושב יש מגרשים ריקים שמחכים לבית.
- **מכולות** 📦: מכולת אופנועים (3 אופנועים) עולה 120, ומכולת רכבים (ג'יפ וטרקטורון) עולה 200. הרכבים מגיעים בצבע שלך.
- **צ'אט** 💬 עם החברים.
- **👊 הרבצה**: יש כפתור, אבל **מי שמרביץ מגורש מהמשחק** לכמה דקות.

## שליטה

| פעולה | מחשב | טלפון |
|---|---|---|
| תזוזה | חיצים / WASD | גוררים אצבע על המסך |
| עלייה וירידה מרכב | E או רווח | כפתור "עלה" |
| בניית בית | B, ואז Enter לאישור | "בנה בית", ואז "בנה כאן" |
| צ'אט | Enter | "צ'אט" |

## הגדרות (משתני סביבה)

| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `PORT` | 3000 | הפורט |
| `PUBLIC_URL` | (זיהוי אוטומטי) | הכתובת שתופיע ב-QR, למשל כשהמשחק עלה לאינטרנט |
| `BAN_MINUTES` | 3 | כמה דקות מי שהרביץ מגורש |
| `START_COINS` | 80 | כמה מטבעות מקבל שחקן חדש |
| `SAVE_FILE` | `world.json` | איפה נשמרים הבתים, המכולות והמטבעות |

העולם נשמר אוטומטית, כך שהבתים והמכולות נשארים גם אחרי הפעלה מחדש.

## לשחק עם חברים שלא נמצאים באותו בית

כדי לשחק עם חברים שגרים במקום אחר, מעלים את המשחק לשירות כמו Render או Railway (Web Service עם הפקודה `npm start`). אפשר גם להריץ מנהרה זמנית, למשל `npx localtunnel --port 3000`, ולהגדיר את `PUBLIC_URL` לכתובת שמתקבלת, כדי שה-QR יוביל אליה.
