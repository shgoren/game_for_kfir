# 🏜️ עין יהב אונליין

משחק רשת על הערבה. מתחילים באמצע השטח עם אופנוע, טרקטורון או ג'יפ, מוצאים את המקום ומקימים את מושב עין יהב. אחר כך בונים יחד את בית משפחת מזור, הולכים לבית הספר ולנוער, מתחרים בחוגים ומטיילים במושבים השכנים.

## הפעלה

```bash
npm install
npm start
```

פותחים במחשב את `http://localhost:3000`. החברים (מחוברים לאותו WiFi) סורקים את קוד ה-QR ונכנסים מהטלפון.

## איך משחקים

1. **בוחרים רכב** (אופנוע, טרקטורון או ג'יפ) ויוצאים לשטח. כולם מתחילים עם **3,000 🪙**, ומי שנכנס דרך ה-QR מקבל עוד **200 🪙**.
2. **מוצאים את המקום** לפי החץ הצהוב. כשמגיעים לדגל, המושב עין יהב קם מול העיניים.
3. **המשימות** (לוחצים על הכרטיס הצהוב כדי לראות את כולן):
   - 🧱 קונים חומרי בניין במרכז הקניות.
   - 🏡 בונים יחד את **בית משפחת מזור** במרכז המושב: יסודות, קירות, חלונות, גג וגינה. כל מי שעוזר מקבל כסף כששלב מסתיים.
   - 📚 בית הספר: שיעור קצר, וכל תשובה נכונה שווה כסף.
   - 🚩 פעולה בנוער: מרוץ דגלים ברגל.
   - 🏍️ תחרות אופנועים במסלול המוטוקרוס, עם קפיצות.
   - 🚲 חוג אופניים ו־🏊 טריאתלון: שחייה בבריכה, אופניים וריצה.
   - 🚙 טיול ג'יפים וטרקטורונים במושבים השכנים: חצבה, עידן, ספיר, צופר, פארן וצוקים.
   - 🏠 בונים בית משלך.
4. **מרוויחים כסף** מתחרויות (מדליית זהב מביאה הכי הרבה), מבית הספר, מקטיף פלפלים 🌶️ בחממות ומביקור במושבים.
5. **קונים** בסוכנות הרכב (אופניים, אופנוע, טרקטורון, ג'יפ, טרקטור או מכולות עם רכבים), בחנות הכובעים ובסופר (אוכל נותן ריצה מהירה ⚡).
6. **עם חברים**: אפשר לעלות כנוסע על הרכב של חבר (בג'יפ יש 4 מקומות), לכתוב בצ'אט ולהתחרות בטבלת השיאים.
7. **👊 מי שמרביץ מגורש מהמשחק.**

## שליטה

| פעולה | מחשב | טלפון |
|---|---|---|
| תזוזה | חיצים / WASD | גוררים אצבע על המסך |
| עלייה וירידה מרכב | E או רווח | "עלה" |
| כניסה לחנות, לבית ספר או לתחרות | F | הכפתור הצהוב |
| בנייה | B | "בנה" |
| מפה גדולה | M | לוחצים על המפה הקטנה |
| משימות | Q | לוחצים על כרטיס המשימה |
| צ'אט | Enter | "צ'אט" |

## הגדרות (משתני סביבה)

| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `PORT` | 3000 | הפורט |
| `PUBLIC_URL` | (זיהוי אוטומטי) | הכתובת שתופיע ב-QR |
| `START_COINS` | 3000 | מטבעות התחלה |
| `QR_BONUS` | 200 | מתנה למי שנכנס דרך QR |
| `BAN_MINUTES` | 3 | כמה דקות מי שהרביץ מגורש |
| `SAVE_FILE` | `world.json` | איפה נשמר העולם |

העולם נשמר אוטומטית: בתים, מכולות, רכבים, מטבעות, משימות, בית מזור ושיאים.

## לשחק עם חברים שגרים במקום אחר

מעלים את המשחק לשירות כמו Render או Railway (Web Service עם הפקודה `npm start`). אפשר גם להריץ `npx localtunnel --port 3000` ולהגדיר את `PUBLIC_URL` לכתובת שמתקבלת.
