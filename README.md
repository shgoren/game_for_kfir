# 🏜️ עין יהב אונליין

משחק רשת על הערבה. מתחילים באמצע השטח עם אופנוע, טרקטורון או ג'יפ, מוצאים את המקום ומקימים את מושב עין יהב. אחר כך בונים יחד את בית משפחת מזור, הולכים לבית הספר ולנוער, מתחרים בחוגים ומטיילים במושבים השכנים.

## הפעלה

```bash
npm install
npm start
```

פותחים במחשב את `http://localhost:3000`. החברים (מחוברים לאותו WiFi) סורקים את קוד ה-QR ונכנסים מהטלפון.

## איך משחקים

המשחק בתלת־ממד, עם מדבר אמיתי: דיונות, גבעות, סלעים, ואדיות, עצי שיטה, דקלים, הרי אדום במזרח וחיות (צבאים, יעלים, גמלים, כלבים במושב וציפורים).

1. **מתחילים כמשפחה**: אתה, אשתך ושני הילדים, במחנה באמצע השטח, עם אופנוע שטח, טרקטורון או ג'יפ. בג'יפ כל המשפחה נוסעת איתך, וכשהולכים ברגל היא הולכת אחריך.
2. **מוצאים את המקום** לפי האור הצהוב. כשמגיעים, מושב עין יהב קם מול העיניים.
3. **להתקיים**: למשפחה יש מים 💧 ואוכל 🍞. שותים בחינם במעיין עין יהב או בברז ליד מגדל המים, וקונים אוכל בסופר.
4. **משיגים כלים** 🔨 בחנות הכלים, או מוצאים ארגזי כלים 🧰 שמוסתרים בשטח.
5. **בונים**: בתים למשפחה, ויחד עם כולם את **משק מזור** במרכז המושב (יסודות, קירות, חלונות, גג וגינה).
6. **מביאים עוד אנשים**: במזכירות המושב מביאים משפחות חדשות. כל משפחה מקבלת בית, והמושב גדל.
7. **מרוויחים כסף**:
   - תחרויות: אופנועי שטח במוטוקרוס, טרקטורונים בדיונות, אופניים וטריאתלון.
   - קפיצות בפארק הקפיצות: כל קפיצה באוויר שווה כסף.
   - עבודה: הובלת ארגזי פלפלים מהחממות לבית האריזה, וקטיף פלפלים 🌶️.
   - בית הספר, ופעולה בנוער.
   - גילוי מקומות: המעיין עין יהב, מצפור חופירה, השיטה הגדולה, דרך השלום והרי אדום.
   - טיולים במושבים השכנים: חצבה, עידן, ספיר, צופר, פארן וצוקים.
8. כולם מתחילים עם **3,000 🪙**, ומי שנכנס דרך ה-QR מקבל עוד **200 🪙**.
9. **👊 מי שמרביץ מגורש מהמשחק.**

## שליטה

| פעולה | מחשב | טלפון |
|---|---|---|
| תזוזה | חיצים / WASD | גוררים אצבע על המסך |
| עלייה וירידה מרכב | E או רווח | "עלה" |
| כניסה לחנות, לבית ספר או לתחרות | F | הכפתור הצהוב |
| בנייה | B | "בנה" |
| מפה גדולה | M | לוחצים על המפה הקטנה |
| משימות | Q | לוחצים על כרטיס המשימה |
| צ'אט | Enter | "צ'אט" |

## הגדרות (משתני סביבה)

| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `PORT` | 3000 | הפורט |
| `PUBLIC_URL` | (זיהוי אוטומטי) | הכתובת שתופיע ב-QR |
| `START_COINS` | 3000 | מטבעות התחלה |
| `QR_BONUS` | 200 | מתנה למי שנכנס דרך QR |
| `BAN_MINUTES` | 3 | כמה דקות מי שהרביץ מגורש |
| `SAVE_FILE` | `world.json` | איפה נשמר העולם |

העולם נשמר אוטומטית: בתים, מכולות, רכבים, מטבעות, משימות, בית מזור ושיאים.

## לשחק עם חברים שגרים במקום אחר

מעלים את המשחק לשירות כמו Render או Railway (Web Service עם הפקודה `npm start`). אפשר גם להריץ `npx localtunnel --port 3000` ולהגדיר את `PUBLIC_URL` לכתובת שמתקבלת.
