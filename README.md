# 🏜️ עין יהב אונליין

משחק רשת על הערבה. מתחילים באמצע השטח עם אופנוע, טרקטורון או ג'יפ, מוצאים את המקום ומקימים את מושב עין יהב. אחר כך בונים יחד את בית משפחת מזור, הולכים לבית הספר ולנוער, מתחרים בחוגים ומטיילים במושבים השכנים.

## הפעלה

```bash
npm install
npm start
```

פותחים במחשב את `http://localhost:3000`. החברים (מחוברים לאותו WiFi) סורקים את קוד ה-QR ונכנסים מהטלפון.

## איך משחקים

המשחק בתלת־ממד, עם מדבר אמיתי: דיונות, גבעות, סלעים, ואדיות, עצי שיטה, דקלים, הרי אדום במזרח וחיות (צבאים, יעלים, גמלים, כלבים במושב וציפורים).

1. **מתחילים כמשפחה**: אתה, אשתך ושני הילדים, במחנה באמצע השטח, עם אופנוע שטח, טרקטורון או ג'יפ. בג'יפ כל המשפחה נוסעת איתך, וכשהולכים ברגל היא הולכת אחריך.
2. **מוצאים את המקום** לפי האור הצהוב. כשמגיעים, מושב עין יהב קם מול העיניים.
3. **להתקיים**: למשפחה יש מים 💧 ואוכל 🍞. שותים בחינם במעיין עין יהב או בברז ליד מגדל המים, וקונים אוכל בסופר.
4. **משיגים כלים** 🔨 בחנות הכלים, או מוצאים ארגזי כלים 🧰 שמוסתרים בשטח.
5. **בונים**: בתים למשפחה, ויחד עם כולם את **משק מזור** במרכז המושב (יסודות, קירות, חלונות, גג וגינה).
6. **מביאים עוד אנשים**: במזכירות המושב מביאים משפחות חדשות. כל משפחה מקבלת בית, והמושב גדל.
7. **מרוויחים כסף**:
   - תחרויות: אופנועי שטח במוטוקרוס, טרקטורונים בדיונות, אופניים וטריאתלון.
   - קפיצות בפארק הקפיצות: כל קפיצה באוויר שווה כסף.
   - עבודה: הובלת ארגזי פלפלים מהחממות לבית האריזה, וקטיף פלפלים 🌶️.
   - בית הספר, ופעולה בנוער.
   - גילוי מקומות: המעיין עין יהב, מצפור חופירה, השיטה הגדולה, דרך השלום והרי אדום.
   - טיולים במושבים השכנים: חצבה, עידן, ספיר, צופר, פארן וצוקים.
8. כולם מתחילים עם **3,000 🪙**, ומי שנכנס דרך ה-QR מקבל עוד **200 🪙**.
9. **👊 מי שמרביץ מגורש מהמשחק.**

## שליטה

| פעולה | מחשב | טלפון |
|---|---|---|
| תזוזה | חיצים / WASD | גוררים אצבע על המסך |
| עלייה וירידה מרכב | E או רווח | "עלה" |
| כניסה לחנות, לבית ספר או לתחרות | F | הכפתור הצהוב |
| בנייה | B | "בנה" |
| מפה גדולה | M | לוחצים על המפה הקטנה |
| משימות | Q | לוחצים על כרטיס המשימה |
| צ'אט | Enter | "צ'אט" |

## הגדרות (משתני סביבה)

| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `PORT` | 3000 | הפורט |
| `PUBLIC_URL` | (זיהוי אוטומטי) | הכתובת שתופיע ב-QR |
| `START_COINS` | 3000 | מטבעות התחלה |
| `QR_BONUS` | 200 | מתנה למי שנכנס דרך QR |
| `BAN_MINUTES` | 3 | כמה דקות מי שהרביץ מגורש |
| `SAVE_FILE` | `world.json` | קובץ שמירה מקומי |
| `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` | — | שמירה בענן (ראו למטה) |

העולם נשמר אוטומטית: בתים, מכולות, רכבים, מטבעות, משימות, בית מזור ושיאים.

## להעלות את המשחק לאינטרנט (בחינם, בלחיצה אחת)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/shgoren/game_for_kfir)

1. לוחצים על הכפתור למעלה ונרשמים ל-Render עם חשבון ה-GitHub.
2. מאשרים ל-Render גישה לריפו `game_for_kfir` ולוחצים **Apply** / **Deploy**.
3. אחרי כמה דקות מקבלים כתובת קבועה, למשל `https://ein-yahav-online.onrender.com`. זה המשחק, וכל אחד בעולם יכול להיכנס אליו. גם קוד ה-QR במשחק מוביל אוטומטית לכתובת הזו.

ב-Render בחינם, אחרי רבע שעה בלי שחקנים השרת "נרדם", והכניסה הבאה לוקחת בערך דקה. כשהוא נרדם הוא גם שוכח את הקבצים שלו, ולכן צריך לשמור את העולם בענן (הסבר מיד למטה).

## איך העולם נשמר 💾

**בלי שום הגדרה:** כל 30 שניות כל שחקן מקבל לטלפון או למחשב עותק גיבוי של כל העולם. כש-Render מעיר את השרת ריק, השחקן הראשון שנכנס מחזיר אוטומטית את העולם מהגיבוי שלו: בתים, משק מזור, משפחות, מטבעות ומשימות. בגיבוי אין קודים וזיהויים של שחקנים אחרים.

הגיבוי לא יעזור רק אם כל השחקנים מחקו את המשחק מהמכשירים. בשביל ביטחון מלא אפשר להוסיף גם שמירה בענן:

## לשמור את העולם בענן (חינם, לא חובה) ☁️

בלי זה, כל פעם ש-Render מרדים את השרת, הבתים, המטבעות והמשימות נמחקים. עם זה, הכול נשמר לתמיד.

1. נרשמים בחינם ל-**[Upstash](https://console.upstash.com)** (אפשר עם חשבון גוגל או גיטהאב).
2. לוחצים **Create Database** (סוג Redis), נותנים שם, למשל `ein-yahav`, ובוחרים אזור קרוב, למשל Frankfurt. בוחרים במסלול **Free**.
3. בעמוד של המאגר, באזור **REST API**, מעתיקים שני דברים:
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`
4. ב-Render נכנסים לשירות ← **Environment** ← **Add Environment Variable**, ומוסיפים את שני המשתנים עם הערכים שהעתקתם.
5. לוחצים **Save Changes**. השרת יופעל מחדש לבד.

כדי לבדוק שזה עובד, פותחים את `https://<הכתובת-שלכם>.onrender.com/info`. אמור להופיע שם `"storage":"cloud"`. בלי ענן יופיע `"storage":"player-backups"`.

השרת שומר לענן כל 15 שניות כשמשהו משתנה, וגם רגע לפני שהוא נרדם.

## קוד שחקן 🔑

לכל שחקן יש קוד אישי של 6 תווים. רואים אותו בכפתור 🔑 למעלה במשחק.
אם מחקתם את האפליקציה, החלפתם טלפון או נכנסתם ממחשב אחר, לוחצים במסך הכניסה על **"🔑 כבר שיחקת?"** ומקלידים את הקוד. כל מה שהשגתם חוזר.

## להתקין כאפליקציה בטלפון או במחשב

אחרי שהמשחק באינטרנט, נכנסים לכתובת שלו:
- **אנדרואיד / מחשב (כרום או אדג'):** לוחצים על הכפתור **📲 התקן את המשחק** במסך הכניסה, או על סמל ההתקנה בשורת הכתובת.
- **אייפון / אייפד (ספארי):** כפתור השיתוף ⬆️ ← **"הוספה למסך הבית"**.

המשחק מופיע עם אייקון משלו ונפתח במסך מלא, כמו אפליקציה רגילה.
